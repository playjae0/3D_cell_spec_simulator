# 부품 상태·지지 블록·단면 후속 구현

## 변경 범위와 조작

1. **셀 구성 부품**에 양극/음극 각각 `포일 탭 · 집속 전`, `포일 탭 · 가용접 후`, `포일 탭 · 커팅 후`를 둔다. 공정 공구에서 `가용접 포일 집속` 카드는 제거했다. 기존 집속 입력 데이터는 보존하며 포일 상세에서 편집한다.
2. **공정 공구 → 혼/엔빌**에 치형 뒤 지지 블록을 CAD 솔리드로 추가했다. 왼쪽 `지지 블록 깊이` 또는 오른쪽 치수 선택에서 편집한다. 치끝 접촉면은 고정, 치근에서 제품 반대 방향으로 블록을 생성한다. 가상 기본값 3 mm이며 실제 홀더·몸통 도면을 추정한 형상이 아니다.
3. **부품 상세 → 중심 단면**은 기본적으로 공구의 Y 중심 / 파우치 선택 컵의 X 중심을 사용한다. 방향 X/Y/Z 및 절대 위치(mm)를 지정할 수 있다. 위 3D는 절단 표시, 아래 2D는 그 평면과 메시가 만나는 교차선이다. 메시 단면선은 설명용이며 정밀 치수의 기준은 서버 CAD feature이다.
4. **부품 상세에서 치수 편집:** 기존 왼쪽 입력을 유지하고 오른쪽 단품 CAD와 연결했다. 왼쪽 치수 클릭 또는 3D 치수 선택 후 `선택 치수 편집`을 누른다. 혼/엔빌 및 파우치는 CAD 미리보기 후 적용/취소한다. 포일/리드 등 기본 부품은 자동 갱신 또는 `치수 적용 · CAD 재생성`을 사용한다.
5. **읽기 전용 링크:** 선택·단면·회전 가능, 치수 변경/저장/STEP 잠금. 이유와 로컬 실행 방법을 상세 상단에 명시한다. 가짜 계산으로 편집을 흉내내지 않는다. 로컬 `scripts/start.ps1` (Windows) / `sh scripts/start.sh` (Linux)로 실행하면 같은 부품 상세에서 실시간 편집한다.

## 데이텀과 후공정

| 변경 | 고정 | 이동/종속 | 호환성 |
|---|---|---|---|
| 포일 절단량 | 적층 끝·뿌리·집속 시작면 | 가용접 포일 끝 → 커팅 후 끝; S3/S4/패키지 내부 포일에도 적용 | R4 극별 `foilCut.removedLength`; 누락은 0, 원래 입력 덮어쓰기 없음 |
| 지지 블록 깊이 | 치끝·치근·작업면 U/V | 블록 후면만 제품 반대 방향 이동 | 원래 접촉면/치형 ID 유지; 별도 `.body` ID |
| 치높이 | 기존 치끝 면 | 치근 + 블록 전체가 높이 차이만큼 이동 | 피치·반대 공구·반대 극 독립 |
| 파우치 깊이 | 해당 컵 입구 림 | 바닥·외장; 수납 검증과 후공정 포켓 | 반대 컵 입력 독립 |
| 바닥/림/평면 R | 각 원래 기준 | 해당 전이 곡선 및 계산 바닥 치수 | 각각 별도 CAD feature/치수선 |
| 단면 위치 | CAD 원본·설계·주석 | 화면에서 보이는 절단 범위/교차선 | 설계 변경이나 프리뷰 기록 추가 없음 |

`S2C foil_trimmed`를 S2와 S3 사이에 추가했다. 기존 S3~S6 식별자는 변경하지 않는다. 양극 절단량 1.0 mm / 음극 0.6 mm는 공개 R4·대표 셀 예시값이다. 기존 비-R4 모델의 S2C는 절단량 미지정(0)으로 표시하며, 존재하지 않던 절단을 암묵적으로 생성하지 않는다. 집속 투영 수축과 절단량은 독립이다. 절단이 용접/테이프 관리 영역을 침범하면 CAD 오류로 거부한다.

## 검증과 제한

`live-*`는 로컬 CAD 편집, `preview-*`는 서버 없는 동일 정적 배포물, `deployed-*`는 실제 배포 사이트 확인이다. 공개 예제의 새 개정은 대표 셀 `phase1-2`, R4 예제 `R4-demo-2`, 공구 `example-2-block`이다. 최종 로컬 편집 시험은 `phase1-2`에서 재실행했다.

### 남은 제한

- 단면은 표시 메시 교차선이다. 임의 방향 스케치 절단면·정밀 단면 도면 내보내기는 이번 범위가 아니다.
- 깊이·R·폭·피치 등 등록 치수는 치수선으로 표시한다. 전용 기준이 아직 없는 메타데이터/배치 항목은 영향 부품을 강조하고 미지원 치수선임을 표시한다.
- 실제 공구 바디 치수·치끝 평탄부·체결 형상·포일 절단 공차는 사내 입력이 필요하다. 블록은 가상 예시이다.
- 실제 Windows 사내 PC/iPad Safari는 별도 확인 필요. 실행 안내와 의존성은 README를 따른다.
