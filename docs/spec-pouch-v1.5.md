# v1.5 파우치 공정 명세

기준 main `cde0950`, 2026-11-18. `Cell_v1_4_Review_and_Pouch_Handoff.zip`의 00/01/02와 조사 자료를 읽고 기존 탭·리드·테이프 CAD, 모델/개정/실측/비교/저장 기능 위에 추가한다. 실제 제품 치수는 없다. `examples/pouch-process.json`과 intake 1.2 예제는 모두 가상값이다.

## 공정과 호환

공유 계약 `src/data/stages.json`을 JS와 Python이 읽는다. S0–S4 및 `packaged`, `finished`는 기존 의미/형상을 유지한다. `product.pouchProcess`를 선택한 모델만 아래 흐름을 사용한다.

| ID | 반제품/적용 입력 |
|---|---|
| pouch_formed | 상하 외장만. 조립체 값은 미입력이어도 성형 CAD 생성 가능 |
| loaded | S4 내부 조립체와 합류. 고유 치수를 바꾸지 않는 강체 위치/자세 |
| sealed | 독립 상하·네 변 작업면과 제품 위 공칭 영역, 상하 공통 영역 |
| trimmed | 원재료와 별도 keep-boundary로 CAD 재료 제거 |
| folded | 절단 후 재료의 긴 변 순차 원통 절곡 |

구 입력 1.0/1.1은 새 치수로 자동 채우지 않는다. 기존 JSON의 스키마 3/4와 modelVersion은 유지한다. 선택 확장은 `pouchProcess.version=1`, 입력 양식은 1.2다. 기존 개정/샘플/프리셋은 그대로 유지된다. 상세 입력이 없는 모델에서 새 파우치 공정을 고르면 누락 사유와 마지막 유효 형상을 유지한다.

## 좌표와 생성 관계

- 파우치 조립 프레임: mm, X 길이/Y 폭/Z 두께, 원점 (0,0,0). 검사 프레임은 기존 origin + rotationZ이며 배치 프레임과 별도다.
- 조립체 로컬: 원래 A/B/C와 부품 치수 유지. assemblyPose는 X→Y→Z 회전 후 XYZ 이동. OCC 형상·표시용 형상·feature 점/원호/선분·법선·patch 방향·포일 보조선에 같은 변환을 적용한다. 월드 X/Y/Z 치수는 투영 거리다. 대응 면 두께는 실제 법선 거리다.
- 시트 재료 좌표: 절단 전 X/Y, 원래 상하 필름의 Z. 절단 경계/작업면/접힘선 ID는 이 좌표에 저장한다. 화면 삼각형 번호를 저장하지 않는다.
- 상하 개구, 깊이, 바닥 R, 림 R, 평면 R, 공칭 두께가 독립이다. 내면 개구 기준으로 바닥 평탄부 = 개구 − 2×(바닥 R+림 R). 수직 벽이므로 바닥 폭/경사를 추가 독립 입력으로 두지 않는다.
- `seamGap`은 조립 원점에서 상하 플랜지 내면 ±gap/2의 공칭 간격이다. 압착 완료 두께나 실제 융착 상태가 아니다. 예제의 gap=0에서는 리드/하부 포켓 국부 간섭이 검출된다. gap=2 가상 검토에서는 간섭이 해소되지만 그 공칭 벌어짐을 열융착 완료라고 해석하지 않는다.

## 지원하는 형상과 검증

상하 독립 이중 컵 + 분리 두 장 외장 + 수직 벽을 지원한다. 단일 컵, 한 장 연결 외장, 경사 벽은 명시적으로 거부한다. 필름은 내면에서 공칭 두께만큼 법선 오프셋한 솔리드이며, 반경 조건을 조용히 보정하지 않는다.

수납 간극은 조립체의 실제 면/코너에서 시작하는 방향 광선과 BRep 표면의 교차로 계산한다. 각 위치는 검사 항목으로 추가할 수 있다. 교차 없는 방향은 미계산으로 표시한다. 포켓/플랜지와 내부 부품의 실제 공통 체적을 검사해 간섭을 표시한다. 간극은 샘플 방향 기준이며 전 표면 최대 침투 깊이를 의미하지 않는다.

작업면은 상하×네 변 8개의 안정 ID, U/V/N, 적용 변, 위치/길이/폭/코너 R을 가진다. X 변의 U=Y, Y 변의 U=X, V는 외측, N은 제품을 향한다. 선택형 relief는 작업면에서 빠지는 영역이다. 제품 절단과 독립이다. 도구 전체 설비와 열융착 강도는 만들지 않는다.

제품 `seal.*`은 실제 남아 있는 재료와 작업면의 교집합이다. 상하 각각과 `seal.common.*`을 구분한다. 원래 공칭 실링 정의를 유지하면서 절단 침범을 진단한다. 작업면은 기본 숨김이고 부품 목록에서 표시 가능하다. 도구와 영역은 STEP 물리 솔리드에서 제외한다.

실런트 중심선의 XY 투영과 작업면 BRep의 교차 구간으로 겹침·끝단 경계 거리를 계산한다. 실제 3D 최소 거리와 구분하며, 작업면 relief는 빠진 교차 구간으로 취급한다. 리드 중심/양측/바깥 프리셋은 전역 Y 단면이므로 수납 회전 후 리드 법선 단면이라고 해석하지 않는다.

절단은 각 시트의 네 절대 경계 내부를 남긴다. CAD 체적/외곽이 실제 바뀌며 원재료 끝 참조는 `material_removed`로 무효화한다. 실링 외측에서 남길 끝까지 U 방향 세 위치의 잔여 폭과 실제 변형 후 끝점 거리를 구분한다. 코너 노치/임의 cutout을 기본 추가하지 않는다.

접힘은 ±Y 각각 최대 두 개의 안정 ID를 제공한다. 활성화, 순서, 재료 접선 시작선, 부호 각도, 내측 R을 입력한다. 원호와 접힌 평면을 유한 두께의 정확한 OCC 단면으로 만들고 X 방향으로 압출한다. 지정 기준층은 전체 공칭 상하 포락 두께의 비율(기본 0.5)이다. 해당 층의 호 길이+직선 길이를 보존한다. 다른 층의 길이는 이 명목 매핑을 따른다. 연신/물성 예측이 아니다.

같은 변의 안쪽→바깥쪽 순서만 지원한다. 역순, 곡률 구간 겹침, 재료 길이 부족, 포켓 침범/상하 시트 교차를 거부한다. 긴 변을 가로지르는 직사각형 실링 영역도 같은 매핑으로 이동한다. 둥근/relief 작업면이 곡률 구간을 가로지르는 조합, 단변/교차 절곡은 현재 거부한다. 자동으로 사각형/평면으로 대체하지 않는다.

## 입력·주석·비교

새 필드 141개는 `src/data/pouch-fields.js`의 실행 가능한 사전에서 입력 양식, 필드 편집, 직접 편집 후보와 연결된다. 비활성 작업/relief 치수는 편집 비활성으로 표시한다. 기존 최신 요청 우선 CAD 큐를 재사용하며 실패 시 확정 형상을 유지한다.

관리 치수는 입력 참조와 CAD 계산 결과를 구분한다. 생성 입력의 focus/hover는 소유 부품 및 등록 참조를 표시한다. 회전 각도·접힘 순서·비율 등 기존 거리/반경 치수선 종류에 해당하지 않는 입력은 값과 대상/방향을 설명하고 가짜 mm 치수선을 만들지 않는다. 일부 작업면 윤곽/relief 세부 값은 소유 영역 강조로 연결하고 개별 치수선 참조는 미지원이다.

포켓 바닥과 긴 변 재료 패치에 표면점을 저장할 수 있다. 고정 mm/정규화 위치는 전개 재료 기준을 유지하고 절곡 후 좌표로 평가한다. 절단 소실 위치를 다른 면에 자동 연결하지 않는다. 기본 측정 세트에 공정 계산 항목을 추가하며, 기존 목표/공차/설명·그룹 표시·검사 보기 기능을 사용한다.

A/B는 기존 독립 CAD/공통 카메라/단면 구조를 유지한다. 외곽/체적에 더해 BRep 면 유형·면적·중심의 서명을 비교한다. 이는 국부 곡면 변화 감지 수단이며 모든 형상의 수학적 동일성 증명은 아니다. R 변경 회귀는 실제 차집합과 단면도 함께 확인한다.

## 범위 밖

실제 상하 융착부 두께 분포·리드 주변 필름의 압착/수지 유동·임의 외곽/주름·한 장 파우치 브릿지·표면 감육 홈·소성/스프링백/용접 강도. 공정별 물리 현상 전체를 시뮬레이션하지 않는다. 실행파일·설치·배포 갱신은 이번 회차에 포함하지 않는다.
