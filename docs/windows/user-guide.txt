CellStudio Windows x64 사내 시험판 — 시작 안내

1. 같은 커밋 이름의 CellStudio-win-x64-….zip과 CellStudio-IntakeKit-….zip을 받습니다.
   GitHub Actions 다운로드는 바깥 ZIP에 배포 ZIP이 들어 있습니다. 안쪽 배포 ZIP까지 압축 해제합니다.
   실행 ZIP 전체를 쓰기 가능한 새 폴더에 풀고 CellStudio.exe를 엽니다.
   ZIP 안에서 직접 실행하거나 EXE만 옮기지 마세요. Python/Node/CadQuery 설치는 필요 없습니다.
   마지막 성공 포트를 우선 사용하고, 없으면 8765부터 확인합니다. 사용 중이면 빈 포트를 자동 선택해
   기본 브라우저를 엽니다. 실제 주소는 실행 창에 표시됩니다. 인터넷 없이 로컬 CAD가 계산합니다.
   브라우저가 안 뜨면 실행 창에 표시된 주소를 입력합니다. Edge/Chrome의 WebGL 지원이 필요합니다.
   이 시험판 EXE는 코드 서명되지 않았습니다. 회사 실행 정책 승인은 담당자에게 확인합니다.

2. 먼저 입력키트의 04_Filled_Virtual_Intake.json으로 시험합니다(공개 가상값).
   화면의 ‘모델/입력 양식’ → ‘입력 양식 / 보관함 가져오기’에서 가져옵니다.
   모델·개정, 생성 공정, 필수값·출처를 확인 → ‘임시 CAD 생성’ → ‘새 모델/개정 적용’.
   사내 자료는 사내 Copilot에서만 처리합니다. 빈 양식 + 필드 사전 + 프롬프트를 함께 제공합니다.
   미확정은 null, 확인된 0은 0입니다. 예시 숫자를 사내 누락값에 채워 넣지 마세요.
   ‘현재 JSON 검토 CSV’로 현재 입력표를 받습니다. JSON을 바꾼 후 CSV도 다시 생성합니다.
   CSV는 검토용이며 가져오기 형식은 JSON입니다. PDF/이미지 업로드는 이번 버전에 없습니다.

3. ‘부품·요소기술’ → 해당 부품 → 치수 선택 → ‘선택 치수 편집’으로 변경합니다.
   공구는 ‘CAD 미리보기’ 후 ‘미리보기 적용’을 눌러 확정합니다. CAD 확정 상태를 확인하세요.
   두 극의 값은 독립입니다. 불가능한 값은 원인을 표시하고 마지막 확정 형상을 유지합니다.

4. 상단 ‘JSON 저장’은 작업 중인 셀 JSON(형상 설정·주석·검사·입력 출처·현재 장면)을 저장합니다.
   ‘입력 양식’ JSON은 검토/모델 생성용이고, ‘셀 JSON’은 작업 복원용입니다.
   셀 JSON은 프로그램 폴더 밖의 승인된 데이터 폴더에 저장하세요.
   재실행 후 상단 ‘불러오기’로 셀 JSON을 엽니다. ‘모델/입력 양식’에 넣는 파일과 구분하세요.
   브라우저 보관함의 여러 모델·개정·실측 이력은 셀 JSON 하나와 다릅니다.
   전체 이력 보존에는 ‘모델/입력 양식 → 전체 보관함 백업 내보내기’를 별도로 사용하세요.
   셀 JSON은 현재 작업 복사본입니다. 수정값을 보관함의 새 개정으로 남기려면 ‘현재 작업 개정 저장’을 사용합니다.
   브라우저 프로필/포트를 바꾸거나 사이트 데이터를 삭제하면 내부 보관함이 달라질 수 있습니다.

5. 저장 후 브라우저를 닫고 CellStudio 실행 창에서 Ctrl+C 또는 창 닫기로 CAD를 종료합니다.
   빈 포트는 자동 선택합니다. 특정 포트를 고정하려면 PowerShell에서 .\CellStudio.exe --port 8766
   으로 실행합니다. 고정한 포트가 사용 중이면 오류를 표시합니다. --port 0은 다시 자동 선택입니다.
   마지막 성공 포트는 %LOCALAPPDATA%\CellStudio\launcher.json에 저장합니다.
   포트가 변경되면 브라우저 보관함은 별개입니다. 기존 셀 JSON/보관함 백업을 가져오세요.
   오류 로그: %LOCALAPPDATA%\CellStudio\logs. 로그/셀 파일을 외부로 보내기 전 사내 규칙을 따릅니다.

업데이트: 새 버전 ZIP을 별도 폴더에 풉니다. 기존 셀 파일의 복사본으로 열기/치수/CAD/저장을 시험한
후 전환합니다. 기존 실행 폴더에 덮어쓰지 마세요. VERSION.json의 커밋이 입력키트와 같아야 합니다.

현업 마지막 시험: 외부 네트워크가 끊긴 사내 Windows x64 PC에서 가상 입력 가져오기 → 모델/개정 확인
→ 양극 혼 블록 깊이 3 → 4 mm → 실제 CAD 변경 → 셀 JSON 저장 → 프로그램 종료 → 재실행 → 셀 열기
→ 4 mm와 형상 확인. PC/OS/브라우저/보안 정책/결과/오류 화면을 사내에 기록하세요.
개발 환경 및 별도 Windows 러너 검증은 사내 정책 적용 PC 실기 검증을 대신하지 않습니다.
