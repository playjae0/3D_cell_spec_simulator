# 데이텀 검토 범위와 제출물

최신 작업 브랜치에서 제품 공정·부품 카탈로그 전체를 열거한 뒤 치수가 어떤 기준에 연결되는지 추적한다. 대표 혼 하나의 전후 캡처만으로 데이텀 검토를 종료하지 않는다.

- 셀 A/B/C와 극별 방향 → 적층체 끝면 → 포일 뿌리·집속부 → 리드·용접·테이프·실런트, 파우치 림·브리지 → 컵·가스방 → 수납·실링·절단·폴딩, 공구 로컬 기준 → 장착 기준 → 제품 측정면의 연결을 조사한다. 구 모델 경로에서 해석이 달라지는 경우 별도 행을 둔다.
- 부품 정의, 조립 배치, 공정별 CAD 결과, 화면 치수선, 저장/재열기가 같은 기준을 쓰는지 대조한다. 기준 ID 누락, 고정 세계좌표, 경계상자 중심 재정렬, 축 반전·중복 오프셋, 서로 다른 소유자가 같은 거리를 독립 입력하는 경우에는 해당 기준을 쓰는 모든 부품과 후공정으로 추적을 확장한다.
- 제출물은 실제 조사로 채운 데이텀 대응표다. 열은 모델·공정·극 / 부품·치수 / 원래 입력 경로 / 부모 기준과 자식 결합 기준 / 면·점·축·방향·단위 / 적용 변환 / 치수 변경 시 고정·이동할 대상 / 연결된 측정 개소 / 근거 코드·시험 / 상태로 구성한다. 코드로 확인한 사실, 실행 확인, 사내 기준 미확정을 구별한다.
- 혼·엔빌 치끝과 바닥 중 어느 기준을 고정하는지, 리드 이동 시 실런트의 상대 위치, 파우치 닫힘·절단·폴딩 뒤의 기준 변환을 우선 확인한다. 원래 설계와 구현 근거가 분명한 불일치는 수정하고 전후 수치·회귀 결과를 남긴다. 기준을 바꾸면 기존 모델 의미가 달라지고 사내 기준도 미확정이면 기존 정의를 보존하고 영향 범위와 선택지를 질문한다.
- 보고서에 조사 대상 목록과 빠진 경로, 미검증 환경을 명시하고 대응표 위치를 링크한다. 레이저 전용 신규 기능과 가용접 슬로프 시험을 추가하지 않아도 해당 부품의 기존 배치 기준은 조사할 수 있다.
