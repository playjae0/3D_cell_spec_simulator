# 부품·요소기술 단품 설계 화면

이번 회차의 진입점은 개선된 제품 공정도를 가진 최신 작업 브랜치다. 시작 시 커밋과 Artifact를 확인한다. 이전에 확인한 main 37c668e, 프리뷰 bc7259e는 참고 이력이다. 제품 공정도는 회귀 검사 대상으로 둔다.

| 번호 | 제목 | 구현과 확인 기준 |
|---|---|---|
| 01 | 전체보기 이미지 카드 | 현재 모델의 부품·공구별로 이름과 고정 시점 썸네일을 표시한다. 해당 단품 형상에서 생성하고 단품·개정·형상값별로 캐시한다. 혼과 엔빌은 치면, 레이저는 패턴, 실링은 평면·단면을 보인다. 카드 선택으로 같은 설계의 상세를 연다. 데이터가 없으면 사유를 표시한다. |
| 02 | 상세 화면 배치 | 왼쪽은 단품 사양과 적용·취소, 오른쪽 위는 가장 큰 단품 3D, 그 아래는 작은 완성 셀이다. 공구는 처음부터 접촉면을 향한 사시도로 열고 회전·확대·작업면 정면·맞춤을 제공한다. 상세로 들어왔을 때 셀보다 단품을 먼저 식별할 수 있어야 한다. iPad 가로와 좁은 폭에서 검사한다. |
| 03 | 형상과 조립 배치 분리 | 부품 탭은 내재 치수만 표시한다. 셀 좌표 X/Y/Z, 조립 오프셋·회전, 장착 위치는 라벨·표·툴팁까지 제품 설계 화면에서만 제공한다. 치형 피치, 패턴 내부 간격, 컵 사이 거리처럼 물건 자체를 정의하는 치수는 단품 사양이다. 과거 데이터에서 기능을 숨기는 과정에 값을 초기화하지 않는다. |
| 04 | 데이텀과 재조립 | 각 부품에 기존 설계 의미와 일치하는 로컬 기준면·방향·원점을 식별하고, 셀 쪽에 극·공정별 상대 부품 기준과 조립 변환을 둔다. 공구는 작업면 기준, 리드는 기존 결합 기준, 파우치는 기존 림·브리지 기준을 확인한다. 치수 변경 때 메시 경계 상자의 중심으로 재정렬하지 않는다. 셀에서 위치를 바꾸면 배치만, 부품에서 치수를 바꾸면 같은 기준에 장착된 형상만 갱신한다. 기존 프로젝트 왕복으로 적용 전 위치 보존을 검증한다. 전체 연결 검토와 인계 산출물은 03_DATUM_REVIEW.md를 따른다. |
| 05 | 혼·엔빌 접촉면 3D | 가용접/메인·양극/음극·혼/엔빌의 기존 독립 정의를 재사용한다. 대표 가상형은 격자 배열의 사각뿔 치형으로 한다. 작업면 길이·폭, 너링 영역, 두 방향 피치, 치높이와 기존 치형 종류를 실제 요철에 반영한다. 길이·폭이 영역을 넘거나 치가 겹치는 입력은 명시적으로 처리한다. 경계 처리와 배열 기준을 고정하고 보고한다. 필요하면 기존 호환 형식별로 다른 단면을 유지한다. 바디 치수가 없으면 접촉부만 모델링하고 범위를 표기한다. 노멀맵·격자선만으로 완료 처리하지 않는다. |
| 06 | 레이저 스팟 표시 | 우선순위는 기존 용접면의 기록된 스팟 표시와 설정 보존이다. 신규 배열 편집·경계 검사·전용 3D는 후속으로 둔다. |
| 07 | 리드탭·실런트 결합 단품 | 양극·음극 각각 리드와 부착된 실런트를 한 카드와 한 조립 단위로 그린다. 재질·부품 ID·측정면은 개별 식별 가능하게 둔다. 기존 기준에서 실런트 폭은 리드 폭+양측 돌출량이다. 주의할 점은 bc7259e의 실런트 X가 집속점 기준이었다는 것이다. 가져올 때 기존 리드와 실런트의 상대 좌표를 계산해 원래 조립 형상을 보존한다. 셀에서 결합 단품 전체를 이동하면 둘이 함께 이동해야 한다. 실런트 부재·미확정도 보존한다. 사내 길이 방향 관리 기준 변경은 확인 사항으로 보고한다. |
| 08 | 파우치·테이프 등 단품 | 파우치는 열린 두 컵과 브리지·가스방 여유를 포함해 컵 깊이·라운드 등 단품 형상을 표시한다. 테이프는 실제 설정된 형상과 크기를 보여준다. 셀 부착 오프셋과 제품 수납 위치는 조립 설계에서 다룬다. 단품마다 전체 셀을 복제해 저장하지 않는다. |
| 09 | 실링 2D 설계 | 오른쪽 주 뷰를 접촉면 평면도와 선택 위치의 두께 방향 단면으로 구성한다. 기존 L·R 평면 윤곽과 수평 제약, 탭 바깥의 넓은 폭을 유지한다. 단면에는 참조 위치·방향을 평면도와 대응시킨다. 입력 가능한 단면 치수는 실제 정의가 있는 작업면 높이·단차·R 등으로 한정한다. 자료 없는 단면은 가상 예시임을 표시하며 임의의 제품 압착 결과를 만들지 않는다. 공칭 단면을 편집하면 동일 정의에서 단면을 다시 그린다. |
| 10 | 하단 완성 셀과 적용 결과 | 열 때마다 같은 모델·개정의 완성 셀이 기본이다. 리드·실런트 등 잔존 부품은 해당 위치를 강조한다. 혼·엔빌·레이저 선택 시 완성 셀에는 공구 자체를 끼워 넣지 않고 식별 가능한 적용 부위를 강조한다. 하단에서만 ‘적용 공정 보기’로 가용접/메인/실링 시점을 볼 수 있게 한다. 원래 공정 화면의 선택을 변경하지 않는다. 기록이나 추적 근거가 없으면 사유를 표시한다. |
| 11 | 라이브·Artifact와 피드백 | 로컬 CAD에서는 편집→계산→적용·취소→저장·재열기를 시험한다. 정적 Artifact는 실제 엔진이 기록한 단품과 셀 결과를 읽기 전용으로 표시한다. 기록 없는 조합은 안내하고 자체 근사 생성하지 않는다. 개발 완료 후 해당 커밋으로 Artifact를 띄우고 재진입 링크와 화면을 남긴다. |
| 12 | 혼·엔빌 3D 직접 편집 | 실시간 CAD에서 치수선이나 대응 모서리를 더블클릭하면 그 자리에서 치수를 수정할 수 있고 왼쪽 사양의 같은 필드와 동기화된다. 터치는 선택 후 치수 편집 버튼으로 같은 편집기를 연다. 후보 치수가 여러 개면 이름을 제시한다. 선택한 극·공정·공구의 안정적인 필드 ID에 연결한다. |
 
## 구현 순서와 인수 시험

먼저 혼 하나로 카드 → 단품 확대 → 피치 변경 → 완성 셀 참고 → 적용 공정 확인을 관통해 구현한다. 이후 엔빌과 나머지 단품에 공통 화면을 적용한다. 엔진의 공칭 접촉면, 개별 치형 기하, 제품의 용접 결과는 구별한다. 치면 세부 메시를 모든 공정·극에서 중복 저장하지 말고 기존 무손실 캐시·기록 경로를 재사용한다.

- 혼의 높이만 바꿔 같은 시점의 측면·사시도에서 전후 높이를 확인한다. 피치만 바꿔 실제 반복 간격을 측정하고 엔빌과 반대 극의 정의가 유지되는지 확인한다. 카메라 회전만으로 요철의 측면이 보여야 한다.
- 조립 데이텀 전후 좌표와 대응하는 결합면을 비교한다. 치높이를 바꿀 때 고정할 기준이 치끝인지 바닥인지 기존 모델 계약을 확인하고 보고한다. 임의로 달라지는 경우 사용자 판단이 필요하다.
- 리드 폭 변경에 따른 실런트 폭, 결합 단품 이동 시 상대 위치 유지, 구버전 모델의 저장·재열기를 시험한다.
- 실링 중앙과 탭 바깥에서 선택한 단면이 평면도의 해당 위치와 맞는지 검증한다. 완료된 제품 공정도의 전체→상세→복귀와 양극 탭 그룹 숨김도 회귀 확인한다.
- 최종 답변 첫머리에 미반영·부분 반영·미검증·사용자 질문을 이유·영향·다음 조치와 함께 쓴다. 01~12 각각 구현 상태, 로컬 CAD 결과, Artifact 결과, 테스트/캡처 근거를 보고한다. 단품 이미지 목록, 혼 피치 전후, 완성 셀 참고 화면, 실링 단면 캡처를 첨부한다. Artifact를 띄우지 못하면 사유와 검증된 배포 ZIP을 제공한다.

- 직접 편집 시험은 혼 피치와 엔빌 치높이를 각각 3D에서 수정하고, 왼쪽 값·재계산된 치형·반대 공구·데이텀 전후를 대조한다. 취소, 유효하지 않은 값, 저장 후 재열기를 확인한다. 정적 Artifact에서는 같은 치수와 기준을 선택·강조할 수 있고 편집 잠금이 유지되어야 한다. 가용접 깊이–포일 슬로프 신규 연동 시험은 후속이다.
