1. S4의 양극/음극 테이프를 각자 선택하고 S0로 되돌려 편집 대상과 선택 강조가 함께 갱신되는지 확인. S3 실런트와 S4 테이프 구별.
2. P0에는 외장만, P1에는 수납 조립체도 선택 가능. P2에서 상/하 및 각 변의 작업면(tool)과 제품 실링 영역(seal)이 해당 입력에 연결되는지 확인. P3 절단/P4 폴딩 및 기존 packaged/finished 호환 경로도 확인.
3. 단면·데이텀을 켠 상태에서 모델의 치수 표시를 껐다 켜고 개별 표시 조합 복원 확인. 기존 리드 단면 컨트롤과 작업면 relief의 입력 조건 유지 확인.

5. 명칭표에서 S4 테이프와 P2 작업면 폭을 찾아 단위·극·기준을 3D에서 대조. 기존 검사 프리셋과 개정 재열기 확인.
