현재 3D_cell_spec_simulator를 아래 요구사항에 따라 개선해줘.
기존에 잘 만들어진 CAD 형상을 활용하면서, 앞 공정 상태와 직접 편집 기능을 추가하는 작업이다.

먼저 현재 브랜치와 구현을 확인하고, 이미 구현된 기능은 재사용하라.
이 문서의 요구사항과 현재 코드의 차이를 정리한 뒤 구현·검증까지 진행하라.

1. 목표와 확정 조건

사용자가 제품을 하나씩 조립한다는 관점으로 부품의 형상, 위치,
치수와 공정별 변화를 이해하고 수정할 수 있어야 한다.

확정 조건:
- 내부 전극조립체는 낱장 적층 구조다. 권취 구조가 아니다.
- Jellyroll이라는 명칭은 이 프로젝트에서 전극조립체 반제품을 지칭한다.
- 양끝에 양극/음극 탭·리드가 있으며, 양극과 음극의 스펙은 독립이다.
- 포일은 뿌리에서 집속부까지 폭이 같다.
- 포일 집속은 두께 방향으로 모이는 형상이다.
- 기존 V자 굽힘/블레이드 특허 형상을 사용하지 않는다.
- 용접 후 사진의 노란 부분은 테이프다.
- 사진으로 확인되지 않은 형상을 특허 실시예로 자동 확정하지 않는다.

이번 작업의 우선순위:
① 포일 폭 유지 수정
② 치수 입력과 3D 대상의 양방향 연결
③ 직접 치수 편집과 자동 형상 갱신
④ 앞 공정 상태 추가 및 용접/테이프 상태 분리

2. 공정 상태 구성

다음 상태를 선택하여 볼 수 있게 한다.
이 순서는 제품 상태를 설명하는 모델이며, 실제 라인의 모든 공정을
재현하거나 작업 조건을 시뮬레이션하는 목적은 아니다.

S0. 적층체 / Jellyroll
- 적층체 본체와 양극·음극의 집속 전 포일 돌출부를 표시한다.
- 포일 뿌리의 위치, 돌출 길이, 폭, 두께 방향 분포를 관리한다.
- 실제 개별 포일 장수나 변형을 알 수 없다면 포락 형상으로 표현한다.
- 포락 형상과 실제 포일 한 장의 두께를 명확히 구별한다.

S1. 탭 정렬·집속 / 용접 전
- 뿌리에서 집속 구간까지 두께 방향으로 모이는 형상을 표시한다.
- 포일 폭은 유지한다.
- 뿌리 위치, 집속 위치, 집속 거리, 집속 후 길이·두께를 편집한다.
- 도구 전체나 집게의 구동 애니메이션은 구현하지 않아도 된다.

S2. 가용접 / Pre-weld 후
- 집속 포일에 가용접 관리 영역을 표시한다.
- 가용접 영역의 위치·길이·폭·개수를 독립 관리한다.
- 가용접과 메인 용접은 다른 ID와 별도 스펙을 갖는다.
- 실제 압흔·눌림·두께 변화는 확인값이 있을 때만 반영한다.
- 값이 없으면 관리 영역만 표시하고 이를 실제 용접 비드로 만들지 않는다.
- 가용접 단계에서 외부 리드가 결합되는지는 확정되지 않았다.
  단계별 리드 포함 여부를 명시적 설정으로 두고, 예시 선택은
  '데모 가정'으로 표시한다. 미확정이라는 이유로 전체 구현을 막지 않는다.
- 절단/트리밍 공정을 임의로 추가하지 않는다.

S3. 메인 용접 후
- 집속 포일, 외부 리드, 접촉 관계, 겹침, 메인 용접 영역을 표시한다.
- 테이프는 아직 표시하지 않는다.
- 기존 메인 용접 형상을 최대한 재사용한다.
- 가용접 영역이 가려져도 관리 정보와 참조 ID는 보존한다.

S4. 테이프 부착 후
- S3 형상을 바탕으로 기존 테이프를 부착한다.
- 테이프 시작/끝/폭/두께/부착면과 피복 범위를 관리한다.
- 테이프를 숨기면 하부 용접 영역과 기준을 확인할 수 있어야 한다.

기존 파우치 패키징/완성 상태:
- 기능을 보존하고 새 앞 공정 상태와 연결한다.
- 이번 작업에서 파우치 성형·실링 상세 모델 전체를 새로 만들지는 않는다.
- 기존 상태가 어떤 단순화와 가정을 사용하는지 표시한다.

3. 상태별 데이터와 연결

각 공정 화면을 별도 모델로 복사해 따로 관리하지 않는다.

- 같은 물리 부품은 상태가 달라도 동일한 partId를 유지한다.
- 부품의 포함 여부, 상태별 형상, 접합 영역을 분리해서 저장한다.
- 형상이 달라지는 경우 같은 의미의 기준은 stable featureId로 추적한다.
- 그 상태에 존재하지 않는 기준은 '해당 상태에서 사용 불가'로 처리한다.
- 앞 단계 치수 변경 시 뒤 단계에서 참조하는 형상과 치수를 갱신한다.
- 뒤 단계의 변경이 앞 단계 형상을 소급 변경하지 않도록 한다.
- 설계 입력, 상태별 형상 결과, 실측값은 구분한다.
- 양극/음극의 공정별 값은 자동 대칭 복제하지 않는다.

4. 포일 폭 수정

현재 rootWidth와 집속 후 width가 달라 폭 방향으로 좁아지는 형상을 수정한다.

- 한 극의 포일 폭을 하나의 기준값으로 관리한다.
- 뿌리와 집속부에 같은 폭을 적용한다.
- 양극 포일 폭, 음극 포일 폭, 외부 리드 폭은 각각 별도다.
- 폭이 같다는 조건으로 Y 중심까지 같다고 자동 확정하지 않는다.
- 기존 데이터의 두 폭이 다르면 차이를 표시하고 명시적인 변환을 제공한다.
- 기존 프로젝트를 조용히 변경하거나 한쪽 값을 임의로 폐기하지 않는다.

5. 위치 결정과 치수

각 부품에 다음 정보를 연결한다.
- 기준 부품/기준면/기준점
- 위치를 결정하는 입력값
- 고정되는 면·끝점·중심
- 자동 계산되는 위치와 치수
- 변경 시 영향을 받는 하위 부품

특히 메인 용접 단계에서는 다음이 보여야 한다.
- 적층체 대비 포일 뿌리 및 집속 위치
- 적층체 또는 집속부 대비 외부 리드 위치
- 포일과 리드의 겹침 길이·폭
- 용접 영역의 위치와 크기
- 리드 끝/탭 끝/측면에서 용접 영역까지 거리

동일 자유도를 여러 입력으로 중복 구속하지 않는다.
예를 들어 리드 끝 위치를 입력으로 선택했다면 겹침 길이는 계산값이 될 수 있다.
위치를 결정하는 기준을 사용자가 알 수 있게 표시한다.

6. 입력 항목과 3D의 양방향 연결

오른쪽 입력 항목에 hover 또는 focus:
- 해당 부품/구간을 강조한다.
- 치수의 시작·끝 기준과 치수선을 표시한다.
- 위치 치수는 기준면과 대상의 관계를 보여준다.
- R은 해당 원호를 표시한다.
- 입력 중에는 강조를 유지한다.

예:
'뿌리 폭' → 뿌리 구간 양끝과 폭 치수선
'집속 거리' → 뿌리 단면과 집속 완료 단면
'집속 높이' → 두께 중앙 기준면과 집속 중심
'리드 위치' → 배치 기준과 리드의 지정 기준점

3D hover:
- 대상의 색 또는 외곽선을 변경한다.
- '양극 > 포일 탭 > 집속부'처럼 이름을 표시한다.

3D click:
- 선택을 고정한다.
- 오른쪽 관련 항목으로 이동하고 펼쳐서 강조한다.

부품/면/모서리/점 선택을 구별한다.
모든 점을 항상 표시하지 말고, 선택 대상과 모드에 필요한 기준만 표시한다.
모바일·터치에서는 탭과 고정 툴팁으로 같은 정보를 제공한다.

7. 모서리 더블클릭으로 치수 편집

사용자가 모서리 또는 표시된 치수선을 더블클릭하면
그 위치에 작은 치수 편집창을 연다.

단, 모서리 하나가 항상 하나의 설계 변수와 대응하는 것은 아니다.

- 대응하는 독립 변수가 하나면 바로 해당 값 편집.
- 길이/위치/R 등 여러 변수가 연결되면 선택 목록 제공.
- 계산 치수이면 '계산값'으로 표시하고 원인이 되는 입력으로 이동.
- 화면상의 모서리 길이를 임의로 설계 변수에 덮어쓰지 않는다.
- 어느 기준이 고정되고 어느 방향으로 바뀌는지 표시한다.
- Enter 적용, Esc 취소, 바깥 클릭 동작을 일관되게 정의한다.
- 드래그 회전과 더블클릭 편집이 충돌하지 않게 한다.
- 터치에서는 선택 후 '치수 편집' 버튼을 제공한다.

기준 연결은 semantic feature에 저장한다.
렌더링 메시의 삼각형 번호를 영구 참조로 사용하지 않는다.

8. 자동 형상 갱신

현재 실행 환경이 실제 /api/rebuild 계산 서버인지 먼저 확인한다.
미리 생성된 메시를 고정 응답하는 프리뷰라면 새 치수를 계산할 수 없다.
이 경우 실제 CAD 계산과 연결하거나 읽기 전용 프리뷰임을 명시한다.

편집 동작:
- 숫자 및 +/- 버튼 변경 시 치수와 변화 방향을 즉시 표시.
- 입력이 잠시 멈추면 CAD 자동 재생성.
- CAD 응답 전에는 '예상 변경'과 '확정 형상'을 구분.
- 연속 변경 요청은 최신 값 위주로 처리.
- 오래된 응답이 최신 형상을 덮어쓰지 않도록 한다.
- 실패 시 마지막 정상 형상을 유지하고 입력 옆에 원인을 표시.
- 미적용/계산 중 상태에서 이전 형상을 새 값의 결과처럼 저장하지 않는다.
- 자동 갱신과 수동 적용 모드를 제공한다.
- 연속 버튼 조작은 한 편집 단위로 undo할 수 있게 한다.
- 기본 카메라 위치는 유지한다. 확대는 명시적인 버튼으로 제공한다.

9. 기본 측정 개소

공정별 기본 측정 템플릿을 제공한다.
기본 치수를 화면에 전부 겹쳐 표시하지 말고 그룹으로 켜고 끈다.

적층체:
길이/폭/두께, 양끝면, 중심면, 포일 뿌리 위치.

집속:
집속 거리, 중심 높이, 폭 방향 편심, 집속 두께.

가용접:
영역 길이/폭, 포일 끝과 측면으로부터 위치.

메인 용접:
리드 위치/돌출, 탭–리드 겹침, 접합 영역 위치/크기.

테이프:
시작·끝 위치, 피복 폭, 용접 영역과의 상대 거리.

입력 항목이나 3D 기준에서 '관리 치수로 추가'할 수 있게 한다.
측정 기준, 방향, 위치를 먼저 보여주고 목표값·공차·실측값을 입력한다.
실측값은 설계 형상을 자동 변경하지 않는다.

10. 후속 파우치 확장을 위한 구조

이번에는 아래 항목의 연결 구조만 확보하고,
미지원 상세 형상을 구현했다고 표시하지 않는다.

- 파우치 성형 개구, 상/하 깊이, 바닥/상단/평면 코너 R
- 파우치 기준의 내부 조립체 수납 위치
- 리드 및 리드 필름과 파우치의 상대 위치
- 실링바 작업면의 위치·크기·윤곽에 따른 실링 영역
- 절단선 및 실링 외측 여유
- 접힘선, 접힘 R·각도, 완성 외곽

기존에 전달한 SKOn_Sealing_Bar_Handoff.zip은 후속 실링 확장의 근거다.
이미 반영된 실링 기능이 있다면 보존한다.
새 작업 때문에 파우치 형상 전체를 다시 만들지 않는다.

11. 완료 확인

아래 시나리오를 실제 화면과 데이터로 확인하라.

- 포일 폭을 수정하면 뿌리부터 집속부까지 같은 폭을 유지한다.
- 양극 편집 시 음극 값이 변경되지 않는다.
- 치수 항목을 가리키면 정확한 구간과 기준이 강조된다.
- 3D 대상에 이름이 뜨고 선택 시 관련 입력으로 연결된다.
- 모서리 더블클릭으로 올바른 독립 치수를 수정할 수 있다.
- 계산값은 직접 덮어쓰지 않고 입력 관계를 안내한다.
- +/- 변경이 실제 CAD 결과에 반영된다.
- 연속 수정 중 오래된 응답이 화면을 되돌리지 않는다.
- 공정 전환에 따라 집속/가용접/메인 용접/테이프 상태가 구별된다.
- 같은 부품과 측정 기준의 연결이 공정 전환 및 JSON 왕복 후 유지된다.
- 앞 단계 변경이 뒤 단계에 반영되며, 뒤 단계 변경이 앞 단계를 오염시키지 않는다.
- 잘못된 입력, 취소, undo/redo, 기존 JSON 불러오기가 작동한다.

최종 보고에는 변경 파일, 사용 순서, 검증 결과, 남은 한계를 기록한다.
사내 Copilot이 이어서 수정할 수 있도록 데이터 구조,
필드와 형상의 연결표, 공정 상태 정의, 기능 추가 위치를 문서화한다.
