# 제품 공정도와 부품·요소기술 UI 검수

## 먼저 알려줄 사항

- **미반영** — 01~12의 요청 범위에서 제외한 항목 없음.
- **부분 반영 01·10·12의 최종 전달** — Artifact 배포 성공. 게시 URL에서 검수 브라우저는 “Log in to access”를 표시했고 Continue with ChatGPT는 계정 로그인 화면을 열었다. 이 브라우저에는 소유자 로그인 세션이 없어 게시 URL 안의 S2→실링바 왕복과 인라인 표시는 미검증이다. 관리형 내장 미리보기 또한 포트 4173 바인딩 권한(EPERM)으로 열리지 않았다. 소유자 계정의 브라우저에서 아래 링크를 열거나 검증된 같은 배포용 ZIP을 정적으로 제공하면 된다.
- **미검증 01·10·12** — 게시 URL 내부 동작은 위 이유로 미검증. 동일 배포 파일을 정적 호스트에서 연 인수 시험은 통과.
- **미검증 06·08** — iPad 가로 크기의 터치 입력을 Chromium에서 검증했다. iPadOS Safari·Chrome 실기에서 스크롤 중 오탭, 작은 부품 선택, 프레임 속도는 확인이 필요하다. 아래 경로를 실기에서 한 번 재현하면 된다.
- **사용자 확인 11** — 현재 실런트 X 시작은 집속점에서 바깥 방향 거리다. 사내 기준면이 다르면 같은 숫자가 다른 위치를 뜻한다. 사내 도면에서 사용하는 시작 기준면 및 측정 방향을 확인하면 된다. 이번 가상 예제의 좌표는 보존했다.

### Artifact 배포 및 실제 주소에서 확인한 범위

[인터랙티브 Artifact 다시 열기](https://pouch-cell-phase1.goodlycurio3.chatgpt.site/) · [배포용 ZIP](Cell_UI_Review_95b1f78.zip)

- 배포 소스 커밋 `6c6cdabf00f24ab9c91cb077ef06b15fb65f18f3`, Sites 배포 `appgdep_6afe63575e40819187b992a8f30cc9b4`의 최종 결과는 `succeeded`다. GitHub 앱 및 매니페스트 커밋은 `95b1f78`이다.
- `npm run build:preview`가 공개 예제 4개 × 20개 공정의 실제 CAD 결과를 기록했다. HTTP 200 53건, 도메인 거부 422 27건. 80건 모두 복원 결과와 서버 재요청 바이트가 일치했다. 배포 파일 13개, 14,402,439 bytes. ZIP 2,174,976 bytes, SHA-256 `5f37a978876e3bee8e54da0a766d649cf491bc4bca262ba4b61f222206c4eca4`.
- 게시 주소에 직접 접속해 ChatGPT 로그인 필요 상태를 확인했다. 비공개 접근 권한을 유지했다. 브라우저 인수 시험에서는 이 배포에 사용한 동일 정적 파일을 CAD 서버 없이 제공하고 **전체보기 → 가용접 S2 → 실링바 단품 → 제품 공정도 → 전체보기**를 실제로 눌렀다. 표시 커밋, 양극 L 38 / R 3, 읽기 전용, S2 선택 및 13개 카드 이미지의 일치를 대조했다. 콘솔의 애플리케이션 예외 0건, CAD POST 0건이었다. [최종 첫 화면 캡처](evidence/preview-touch-overview.png)
- ZIP은 루트에 `index.html`이 있다. 압축을 푼 폴더를 정적 호스트에 올리거나, 그 폴더에서 `python -m http.server 8080`을 실행하고 같은 PC에서 `http://127.0.0.1:8080/`을 열면 된다. 사내 파일과 작업지시서의 첨부 이미지는 ZIP에 포함하지 않았다.
