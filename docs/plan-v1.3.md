# v1.3 구현 계획 · 2026-11-17

기준: main 3e0f9f8a3d63601a6f310d6a383f714650dfeff4 (PR #3). 사용자가 Claude에서 실행한 것과 동일한 버전임을 확인했다. 별도 읽기 전용 호스팅 미리보기는 기준이 아니다. 기존 전체 CAD/직접 편집 앱에 증분 적용한다.

1. 입력 계약 pouch-cell-intake/1.0: ZIP 초안 사전을 정리하고 공정/존재/테이프 경로 조건을 실행 코드에 둔다. 생성한 사전·양식·스키마와 회귀 검사로 불일치를 검출한다. parameterId와 instanceId를 영구 키로 사용한다.
2. intake는 미완성 그대로 저장한다. 출처·원 단위·변환·검토·충돌을 보존한다. 선택 공정만 형상 생성에 필요한 값을 검사한다. 데모와 병합하지 않는다. 불가능한 CAD는 기존 검증에서 거부하고 관련 항목을 안내한다.
3. 기존 schema3와 v2 명시적 폭 변환을 보존한다. nullable 설계를 저장하는 새 프로젝트는 schema4로 구분한다. intake와 CAD 입력을 adapter로 연결하며, 비활성 부품은 해석하지 않는다. 기존 schema3는 새 검사 데이텀/앵커 없이도 읽힌다.
4. 모델별 불변 개정 스냅샷과 임시 검토를 분리한다. 업로드/미리보기/취소는 현재 모델 및 undo 이력을 건드리지 않는다. 적용 한 번에 개정 하나를 저장한다. 미리보기 지연 응답은 토큰으로 폐기한다. 실측은 sampleId/modelId/modelRevision/itemId로 별도 보관하고 복제하지 않는다.
5. 모델 목록·신규·새 개정·양식 다운로드·검토표·누락/출처·변경표·별도 CAD 미리보기·적용/취소를 기존 앱에 추가한다. 계약 변경은 수동 검토 기록을 남긴다.
6. 기존 절댓값 거리 모드는 유지한다. signed_coordinate/signed_offset 및 측정별 datumId, 별도 검사 프레임을 추가한다. 표면점 relative와 fixed_mm 기준을 분리하고 범위 이탈을 오류로 표시한다.
7. 사내 Copilot 지침과 가상 예제, 실행·인수 안내를 함께 갱신한다. JS 계약/이력/단위/참조 검사, 기존 CAD 회귀, 실제 브라우저 업로드→미리보기→적용/저장을 확인한다. 실제 Windows/사내 문서 검증과 이번에 실행한 검증을 구별한다.

파우치 포켓 CAD와 일정 실링 폭은 유지한다. 실링바 신규 CAD, 실제 치수 추정, 제조 물리 해석, 새 STEP 기능은 이번 범위에 추가하지 않는다.
