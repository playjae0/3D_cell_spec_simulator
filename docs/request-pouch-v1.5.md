# 파우치부터 완성 외곽까지 — 구현 및 인수 명세

## 확정 원칙
낱장 적층, 양방향 독립 극, 비대칭 치수. 포일은 폭을 좁히지 않고 두께 방향으로 중심 집속한다. 노란 테이프와 리드 실런트는 별도 부품이다. 특수 V-blade 용접 구조는 적용하지 않는다. 기존 탭 용접/테이프 형상을 재설계하지 않는다.
공개 자료는 관리 항목·형상 관계의 존재 근거다. 해당 특허의 모든 구조를 실제 제품으로 채택하거나 도면에서 수치를 추정하여 확정하지 않는다. 가상 예시와 실제 사내 입력을 구분한다.

## 내부 체크포인트 A — 기존 UI와 기준 구조
1. 가상 입력 파일 선택→검토→임시 CAD→적용/취소, S3 실런트, 측정 세트 중복 방지, 프리셋 복원, A/B 카메라/단면, 비어 있지 않은 보관함 백업→병합→재열기를 실제 화면에서 확인한다. 실패는 최소 수정 후 이어간다.
2. 공정의 단순 숫자 크기 비교에 새 단계를 계속 끼워 넣지 않는다. 파우치 성형은 조립체와 별도 반제품이며 수납에서 합류한다. stage별 필요한 입력/부품/작업을 명시한다. JS/Python/입력 계약의 공정 판단을 일치시킨다.
3. 부품 로컬 기준, 조립 기준, 재료 좌표, 검사 기준의 변환 관계를 정의한다. 전체 3D 위치·자세를 지원하면 CAD, 표시, feature/anchor, 법선, 치수 가이드, 직접 편집, 단면/측정에 같은 변환을 적용한다.
4. 생성 입력, CAD 계산 결과, 실측값을 구분한다. 기준 치수 변경의 종속 관계를 UI에서 표시한다.

## B — 성형 및 수납
- 상하 파우치의 개구 길이/폭, 깊이, 바닥 전이 R·림 R·평면 코너 R, 공칭 두께, 필요 시 측벽 경사를 관리한다. 내면/외면 기준을 명시한다. 개구·바닥·경사를 모두 독립으로 두어 과구속하지 않는다.
- 단일/이중 컵, 한 장 접힘/분리 외장 등 유형은 명시적 모델 선택이다. 지원 유형 범위를 보고하고 미지원 조합은 차단한다. 근거 없이 자동 선택하지 않는다.
- 파우치 성형 상태를 조립체 없이 확인할 수 있어야 한다. 두께·R·깊이에 따른 유효 CAD를 만들고 불가능한 조합은 원인과 함께 거부한다.
- 수납 시 조립체와 파우치의 상대 위치/자세를 관리한다. 수납 위치 수정으로 기존 포일/리드의 고유 치수를 바꾸지 않는다.
- 상하/측면/끝단/코너 간극과 간섭을 실제 표면 기준으로 계산한다. 충돌을 해결하려고 부품을 자동 축소하지 않는다.

## C — 실링바 작업면과 제품 실링 형상
- 각 변, 양극단/음극단, 상부/하부를 독립 설정한다. 자동 대칭은 선택 기능으로만 제공한다.
- toolFace: 안정 ID, 적용 공정/변, 로컬 U/V/N 기준, 작업면 윤곽, 위치, 길이/폭, 코너 R, 구역. 선택적인 relief/단차는 사용자가 활성화한 경우에만 생성한다.
- 바 전체 설비를 모델링하지 않아도 작업면과 제품상의 공칭 실링 영역은 표시·선택·치수 편집할 수 있어야 한다.
- sealRegion: 재료 좌표에 붙은 영역, 내측/외측 경계, 원인 toolFaceId, 상하/변 정보를 관리한다. 상하 작업면이 어긋나면 각각의 범위와 공통 영역을 구분한다. 열융착 성능을 예측했다고 표시하지 않는다.
- 바 작업면 윤곽과 최종 제품 두께를 혼동하지 않는다. 실링부 공칭 두께를 지원한다면 별도 입력 및 명시된 형상 가정으로 둔다.
- 리드/실런트/파우치 경로를 리드 중심, 양측 경계, 리드 바깥 단면에서 확인한다. 실런트 겹침·돌출·위치·실링 경계 간 거리를 계산한다. 실제 수지 유동/접합 강도는 범위 밖이다.
- 특허의 tool relief는 제품 절단 노치가 아니며, 표면 감육 notch도 절단 cutout이 아니다.

## D — 절단 및 순차 폴딩
- cutBoundary는 재료 좌표의 실제 남길 외곽/keep-side와 적용 공정/변을 정의한다. 숨기기만 하지 말고 실제 CAD 외곽과 질량/체적에 반영한다.
- 실링 외측 경계→절단선 잔여 폭을 위치별로 관리한다. 실링영역 침범은 경고/유효성 검사한다. 절단으로 소실된 측정 참조는 명시적으로 무효화한다.
- foldOperation은 순서, 선, 방향, 각도, 내측 R, 움직이는 재료 영역, 기준층을 갖는다. 기존 각도 제한만 풀어 폴딩 구현으로 처리하지 않는다.
- 곡률부와 접힌 평면, 두께를 가진 명목 형상을 생성한다. 실링 영역과 측정 참조도 재료와 함께 이동한다. 인접 절곡부 충돌·자기 교차·불가능한 R을 검사한다.
- 전개 길이의 기준층/중립층 가정을 명시하고 그 기준으로 길이 보존을 확인한다. 실제 소성 변형, 연신, 주름, 스프링백은 예측하지 않는다.
- 완성 외곽, 투영 폭, 절곡부 높이/두께, 간섭을 계산한다. 복수 접힘의 순서를 바꾼 경우에도 작업의 참조 안정성을 검증한다.

## E — 기존 플랫폼에 완전 연결
- 모든 입력은 해당 면/선/점과 연결한다. 입력 hover/focus로 3D 대상과 기준/방향을 표시하고, 3D hover로 이름/공정/소유 부품을 보여준다.
- 더블클릭 편집은 대응하는 독립 생성 입력이 있을 때 제공한다. 여러 치수 후보면 선택하게 하고 계산 결과/실측을 임의 생성 입력처럼 수정하지 않는다.
- 증감/직접입력 후 최신 CAD만 표시한다. 오래된 응답이 최신 입력을 덮어쓰지 않게 한다. 실패 시 마지막 유효 상태와 오류 입력을 구분한다.
- 성형 깊이/R, 수납 간극, 실링 폭/위치, 실런트 겹침, 절단 잔여 폭, 폴딩 외곽을 기본 측정 세트와 단면 프리셋에 연결한다.
- A/B 비교에서 공정 부재와 미입력, 형상 변경과 검사 기준 변경을 구분한다. 동일 외곽/체적의 국부 변경도 검증할 방법을 둔다.
- 모델별 설정과 사내 Copilot용 양식을 갱신한다. 각 항목에 단위, 기준, 공정, 극/변/상하, 출처, 입력/계산 구분, 미입력 상태를 기록한다. 0과 미입력을 혼용하지 않는다.
- 구 입력 1.0/1.1 및 기존 stage ID는 명시적 호환/마이그레이션 경로를 둔다. 기존 개정·실측·프리셋을 파괴하지 않는다. 미확정 값을 임의로 채워 상세 형상 완료라고 하지 않는다.

## 필수 검증 사례
| 변경 | 확인할 결과 |
|---|---|
| 상부 깊이만 변경 | 상부 형상/간극 변경, 하부 독립 입력 유지 |
| 조립체 +Y 이동 | 좌우 간극 반대 변화, 파우치 고유 치수/내부 조립체 형상 불변 |
| 양극단 작업면 폭/위치 변경 | 해당 실링 경계/측정 변경, 음극단 불변 |
| 상하 작업면 불일치 | 각각의 작업 영역과 공통 영역 구분 |
| 절단선 이동 | 실제 외곽/잔여 폭 변경, 기존 실링 정의 보존 |
| 실링 영역을 가로지르는 접힘 | 실링영역/유효 측정 참조가 재료를 따라 이동 |
| R만 변경 | 국부 형상/단면 변화 확인, 외곽 박스만 비교하지 않음 |
| 폴딩 순서 및 불가능한 입력 | 올바른 참조 유지 또는 설명 가능한 거부 |
| 저장/가져오기/개정 재열기 | 값·공정·기준·프리셋 일치, 이전 실측 귀속 유지 |

가상 비대칭 모델로 자동 CAD 검사와 실제 화면 검증을 함께 수행한다. 사용자에게 주는 완료 보고서에 구현되지 않은 항목을 숨기지 않는다. 새 명세/계획/검증 문서와 사내 Copilot 안내도 최신화한다.
