# R4 구현·검증 기록

검증일: 2026-11-18 (한국 시간). 기준 main 84d608a. 가상 mm 데이터이며 각 시나리오는 독립적으로 확인했다. Chrome 실제 화면은 CPU CAD 렌더러, 형상·치수는 CadQuery 2.7/OCC. 검증 당시 화면과 CAD 계산을 함께 기록한다.

## 회귀 검사

- 기존 JavaScript 71개와 R4 관련 검사 통과. 신규 검사는 입력 1.3 왕복, 독립 극/공구/스팟 ID, 과거 모델 개정 스냅샷, 기존 파일에 새 값이 생기지 않는 조건, 새 관리 치수를 보존하는 미리보기 병합을 포함한다. 총 76개 통과.
- 기존 CAD 40개 통과. 신규 CAD는 깊이·고정 기준, 반 피치, 레이저 원주/삭제/추가, 원호/추가 타격, 열린 두 컵/수납/가스/절단/폴딩, 홈 교선, 잘못된 깊이와 열린 가스 실링 경로 거절을 검사한다. 신규 8개 통과(기존 포함 48개).
- `npm run build` 성공. 기존 번들 크기 경고는 남아 있다.
- 초기에 발견한 입력 즉시 미반영, 공정 편집 후 새 관리 치수 누락, 열린 필름 맞춤 범위 문제를 수정하고 화면에서 다시 확인했다. 예제 탭측 바 U를 15로 맞춰 브리지에서 가스 외곽 바까지 이어지게 했다. 연결을 끊은 입력은 CAD 오류로 거절한다.

## 확인 범위와 남은 제한

실제 치수·용접 강도·열융착·가스 팽창·필름 유동은 검증하지 않았다. 실링은 정확한 평면 작업면/필름 교집합의 공칭 영역이다. 리드 통과부 국부 필름 변형과 실물 너링 전체의 소성 압흔은 미지원이다. 상세 치형은 매개변수 도면이며 공칭 접촉 범위와 실제 접합 관리 영역을 동일시하지 않는다. 일반적인 임의 곡면 폴딩은 지원하지 않으며 커널의 제한을 벗어나면 오류를 표시한다.

Windows 실장비, GPU 렌더러, 사내 완전 오프라인 배포는 이 환경에서 직접 검증하지 않았다. 이번 R4의 STEP 재가져오기 검증과 설치파일 빌드는 수행하지 않았다. 기존 STEP 회귀 테스트는 유지했다.
