# 셀 공정·요소기술 구현 지시서 R4

playjae0/3D_cell_spec_simulator · 검토 기준 84d608a. 현재 작업 브랜치와 차이를 먼저 확인하고 이미 구현된 동작은 재사용한다. 이 문서가 이번 회차의 단일 기준이다. 과거 인계 ZIP·조사 로그·버전별 검증 캡처는 이번 검토에서 제외한다. 파일 삭제, 저장소 경량화, 범용 리팩터링, 실행파일 빌드, DXF 자동 인식은 다음 회차 대상이다.

## 제품·공구·측정의 관계

낱장 적층체의 양 끝에 양극·음극 리드가 각각 있다. 극별 설계값을 독립 관리한다. 사양은 이를 결정하는 공정에서 한 번 입력하고 후공정은 개정된 형상과 데이텀을 참조한다. 후공정 실측은 공정별로 저장할 수 있다. 설계값, 계산치, 실측을 UI와 양식에서 구분한다. 공구는 모델별 적용 공정·극·공구 개정·배치로 연결한다. 과거 모델 재열기 시 적용 당시의 형상이 재현되어야 한다.

## 공정별 필수 동작

| 공정 | 제품 상태와 편집 | 검수 |
|---|---|---|
| 적층체 → 가용접 | 뿌리부터 집속부까지 포일 폭을 유지한다. 상하 포일을 두께 방향으로 모은다. 상면 기준 침입 깊이로 편집하는 예시에서는 하면·뿌리·진입 X를 고정하고 잔류 두께와 상하 포락선 경사를 계산한다. 기준면과 고정 조건을 화면에 표시한다. | 한 극의 깊이를 변경하고 진입점 Z와 슬로프의 전후 값을 확인한다. 폭·뿌리·반대 극은 동일해야 한다. |
| 가용접 및 초음파 메인 용접 | 요소기술 탭의 첫 화면은 혼·엔빌을 작업면 쪽에서 보는 평면도다. 각 공구의 외곽, 너링 범위, 치형·피치·방향·높이, 위치·회전을 독립 지정한다. 같은 제품 데이텀에서 위·아래 작업면을 겹쳐 본다. 대표 치형 상세와 단면을 보조 뷰로 제공한다. | 혼만 반 피치 옮겨 제품 위 공칭 접촉 위치가 이동하는지, 엔빌과 다른 극은 고정되는지 확인한다. 공구 압흔과 실제 접합 영역을 구별한다. |
| 레이저 메인 용접 → 테이프 | 극별 메인 용접 방식 선택에 따라 탭–리드 겹침면에 스팟의 중심·공칭 직경·행열·피치·회전을 적용한다. 개별 이동·추가·삭제를 지원한다. 이후 노란 용접부 테이프와 리드 실런트는 별도 부품·위치 기준을 유지한다. | 2×3 배열에서 한 점만 이동 후 삭제해 6→5개와 나머지 ID 유지를 확인한다. 중심이 안쪽이어도 원주가 겹침면을 벗어나면 해당 점을 표시한다. |
| 파우치 성형 → 수납 | 성형 직후에는 펼친 필름 한 장에 같은 방향으로 열린 두 컵과 그 사이 브리지, 가스방용 필름 여유부가 보인다. 필름 평면·브리지 중심선·길이 방향 기준에서 각 컵의 입구 위치, 폭·길이·깊이, 평면 코너 R, 입구 R, 바닥 전이 R을 정의한다. 수납 단계에서 한 컵에 조립체를 놓고 브리지를 따라 다른 컵을 닫는다. | 열린 상태에서 두 입구를 동시에 확인한다. 컵 한쪽의 깊이와 바닥 R만 바꾼 뒤 수납 시 리드·실런트가 양 끝 실링 예정 위치에 오는지 확인한다. |
| 탭측·가스방 외곽 실링 | 실링바의 주 편집 대상은 U–V 평면의 닫힌 작업면 윤곽이다. 직선·원호로 내측선·외측선과 끝부분을 편집한다. 공구 원점·축과 제품 기준점·축을 대응시켜 배치한다. 양극/음극·측면 및 상하 바를 구별하고, 바의 투영·상하 유효 중첩·필름 위 공칭 실링 면적을 구별한다. 기본 띠와 선택적인 추가 타격의 합쳐진 영역을 제품 형상·평면·측정에 연결한다. 기존 단면·단차·홈은 선택 위치의 상세 보기로 연결한다. | 양극 내측선 한 구간만 원호로 바꿔 해당 구간의 실링 폭과 면적이 변하는지 확인한다. 리드 중심·좌우 어깨에서 폭과 실런트 중첩을 표시한다. 외곽·음극·리드는 지정대로 고정한다. |
| 가스방 보존 → 최종 실링 → 절단·폴딩 | 측면 여유부가 남은 중간 제품을 만든다. 탭측 실링 시 가스방 쪽 개구, 외곽 실링 후에는 몸체와 통하는 가스방, 최종 실링 후에는 분리된 영역, 절단 후에는 트리밍된 플랜지가 보인다. 가스방 외곽 실링선·몸체 쪽 최종 실링선·절단선은 별도 위치다. 후속 폴딩은 절단 후 남은 형상을 참조한다. | 공정 전환만으로 가스방의 생성·격리·제거 시점을 확인한다. 절단선 이동 시 남은 플랜지 폭이 바뀌고 앞 공정 실링 기록은 유지된다. |

## 데모와 인수

예시 단위는 mm. 기존 가상 셀 치수를 우선 사용한다. 예시로 양극만 한쪽 끝에 내측선 연장 1.0, 음극은 기본 직선 띠, 가스방은 브리지 반대편, 레이저 배열은 2×3으로 둔다. 현 모델의 유효 겹침·여유에 맞게 수치를 조정하고 화면에 가상 예시로 표시한다. 재료 유동·실제 융착 강도·가스 팽창량을 형상값으로 단정하지 않는다.

공정에 보이는 대상만 선택되게 하고, 치수 hover/선택은 형상과 측정 기준을 함께 강조한다. 요소기술 편집→미리보기→취소/적용→저장·재열기를 검사한다. 필드 양식·사내 명칭 매핑·Copilot 입력 가이드에 신규 입력의 ID, 단위, 데이텀, 공정, 극 구분을 반영한다. 기존 셀 파일을 열었을 때 새 가상값으로 덮어쓰지 않는다.

기존 CAD 생성·입력·화면 경로를 사용한다. 구현 후 실제 UI에서 위 표의 전후 시나리오, CAD 형상 또는 교선 측정, 기존 모델 재열기·빌드를 확인한다. 결과는 기능별 재현 방법과 전후 수치를 짧게 보고하고 실제로 검증하지 못한 항목을 명시한다. 근거 자료는 02의 지정 그림만 참조하면 된다.
