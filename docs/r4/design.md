## 데이터와 정확도

기존 모델은 그대로 읽는다. `product.processTooling`이 있는 명시적 R4 모델만 신규 생성 경로를 사용한다. 개정·공정·극·배치와 공구 형상 전체를 프로젝트/입력 양식에 스냅샷으로 저장한다. 도면 입력값은 예시이며 사내 값으로 교체한다. 메시가 아니라 OCC 면/교선에서 공칭 면적과 폭을 계산한다.

포일은 일정 폭의 부드러운 포락 형상이다. 상면 기준 침입 깊이로 상면 Z와 잔류 두께를 구하고 하면·뿌리·진입 X는 고정한다. 용접 강도/실제 포일 변형/너링 압흔 깊이/가스 팽창 예측은 하지 않는다.

신규 R 공정은 기존 P 공정의 의미를 바꾸지 않는다. 필름은 균일 두께와 원통 브리지 접힘을 가정한다. 제품 실링 영역은 평면 투영으로 정의하며, 리드 통과부 필름의 국부 소성 성형과 열융착은 해석하지 않는다. 해당 간섭/중첩은 수치와 경고로 노출한다.

설계 입력, CAD 계산 결과, 기존 치수·스펙의 공정별 실측은 분리한다. 미리보기는 확정 프로젝트를 변경하지 않는다. 취소는 확정 CAD를 복원하고 적용만 이력에 기록한다.

가스방 외곽 실링 단계부터는 탭측 실링과 브리지의 접속, 가스/최종 실링과 양끝 바의 실제 면적 중첩을 검사한다. 예제 양끝 바 U=15는 끝이 브리지 Y=−45에 닿고 가스 외곽 바와 겹치도록 정한 가상 배치다. 열린 경로를 완전 실링으로 표시하지 않는다.
