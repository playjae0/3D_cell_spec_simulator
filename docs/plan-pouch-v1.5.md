# 파우치 공정 구현 계획

작업 시작: 2026-11-18, main `cde0950f6255c946524b05973619750b0e123522`.
ZIP 검토 기준 `644f723` 이후 PR #6은 비교 카메라/표기/저장 흐름과 실제 UI 검증, PR #7은 증빙 이미지 추가다. 해당 변경과 기존 59 JS / 28 CAD 회귀를 보존한다. `docs/validation-ui-v1.4.md`의 실제 입력·병합·비교 검증을 체크포인트 A의 선행 증빙으로 사용하고, 이번 기능을 최종 UI에서 추가 검증한다.

1. 공유 공정 계약을 둔다. 기존 S0–S4와 packaged/finished ID는 그대로 유지한다. `pouch_formed → loaded → sealed → trimmed → folded`는 별도 파우치 흐름이며 loaded에서 S4 조립체와 합류한다. 숫자 순위에 새 공정을 끼우지 않는다.
2. 선택형 `product.pouchProcess`와 입력 계약 1.2를 추가한다. 구 형상은 명시적 legacy 경로로 보존하고, 새 상세 입력이 없는 기존 파일에 실제값을 추정해 채우지 않는다. 가상 비대칭 예제와 빈 사내 양식을 따로 제공한다.
3. 기존 OCC 포켓의 내면 기준 원호/법선 두께를 재사용한다. 상하 독립 컵, 분리된 두 장 외장, 수직 측벽을 우선 지원한다. 한 장 연결 외장/경사 벽은 지원하지 않는다고 명시하고 거부한다. 조립체의 강체 배치를 형상·feature·법선·patch·보조선에 함께 적용한다.
4. 안정 ID의 상하/네 변 작업면과 재료 위 실링 영역을 분리한다. 원호 코너, 선택형 작업면 relief, 공통 작업 영역을 CAD로 계산한다. 형상은 공칭이며 수지 유동·융착 강도나 압축 후 두께를 예측하지 않는다.
5. 재료 좌표의 네 변 keep-boundary로 실제 CAD를 절단한다. 긴 변의 순차 원통 절곡은 재료 길이와 기준층을 명시하고 유한 두께의 호/평면으로 만든다. 지원하지 않는 교차 절곡과 순서/반경 오류를 거부한다. 실링 영역 및 주석을 같은 재료 매핑으로 갱신한다.
6. 기존 필드/직접 편집/측정 세트/단면/프리셋/개정/A-B에 연결한다. CAD 표면 거리·교차 체적과 단면/국부 표면 서명을 검증한다. 자동 회귀와 API 검사 후 실제 화면을 확인하고 별도 결과를 기록한다.

EXE·설치·배포 갱신은 하지 않는다. 사진·특허의 수치와 특수 공법은 채택하지 않는다. 구현 범위/가정/미지원을 명세·검증 문서·Copilot 입력 안내에 기록한다.
