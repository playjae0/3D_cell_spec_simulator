# v0.4 구현과 인계

2026-11-17. 기준 소스는 이 문서를 포함한 커밋입니다.

## 검증 결과

- Node.js 24 Linux: `node tests/model.test.js` 7개 통과, `npm run build` 성공.
- 가상 몸체 길이 200 mm, 대각선 거리와 X 투영 차이 검증.
- 리드 돌출 22→30 mm에 따른 참조 갱신, 사라진 부품 및 라운드에 의해 제거된 코너 무효 처리.
- 1,000개 측정 정의와 표시 여부 JSON 왕복 일치. 미래 버전 및 잘못된 입력 거부.
- 실제 Chrome 화면에서 S1/S2/S3 전환, 폭 70.1 mm 변경 후 표시값 70.10 mm 확인, 측정 추가와 전체 숨기기/표시 확인.
- 검증 브라우저는 WebGL 비활성 상태여서 SVGRenderer 자동 대체 경로를 사용했다. WebGL 경로, 터치, Windows, 파일 선택기를 통한 전체 저장·재열기, 회전 후 포인트 선택은 추가 수동 검증 필요.

## 모델 가정

원점은 몸체 중심, X 길이/Y 폭/Z 두께, mm. S1 젤리롤은 몸체 길이-12, 폭-8, 두께-0.6으로 단순화한다. 탭·용접·테이프는 양끝 대칭 예시이며 실제 내부 구조를 나타내지 않는다. S2 외곽 여유부는 몸체보다 길이20/폭22 mm 큰 예시이다. 해당 영역은 실링 유효 영역이 아니다. 두 리드는 공통 변수로 편집한다. 리드 돌출은 모든 공정에서 가상 외장 끝 기준이며 S1 젤리롤 끝 기준 거리와는 다르다.

## 후속 개발

src/model.js는 형상 및 참조·계산·파일 검증, src/main.js는 렌더링과 조작을 담당한다. 다음 단계에서 viewer/geometry/annotations/data로 더 분리한다. partId를 바꾸면 기존 참조를 조용히 재연결하지 말 것. schemaVersion 또는 modelVersion을 바꾸면 명시적인 마이그레이션을 추가할 것.

초기 브라우저 검토 후 우선: 부품별 독립 변수, 테이프·용접 위치/폭 편집, 스냅 기준 확대와 선택 점 표시, 스펙 공차·검사값 입력, 위치별 두께, 정확한 CAD 및 STEP 검증. 장면은 현재 단일 카메라와 설명이며 여러 설명 장면 관리는 미구현이다.
