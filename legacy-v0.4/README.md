# Cell Spec Lab

파우치 셀 제조 스펙 3D 시제품 v0.4. 모든 형상과 치수는 가상 예시입니다.

## 실행 Windows 및 Linux

Node.js 22.12 이상 권장. 프로젝트 폴더에서:

```sh
npm ci
npm run dev
```

표시된 로컬 주소를 Chrome 또는 Edge로 엽니다. HTML 더블클릭 방식은 지원하지 않습니다.

```sh
npm test
npm run build
npm start
```

빌드 후에는 dist 폴더와 serve.mjs만 복사해 Node.js가 설치된 PC에서 `node serve.mjs`로 실행할 수 있습니다. 실행 위치는 dist와 serve.mjs의 상위 폴더입니다. 주소는 http://127.0.0.1:4173 입니다. 빌드 결과에 Three.js가 포함되므로 실행 중 CDN이나 외부 API는 필요하지 않습니다. 최초 npm ci에는 패키지 다운로드가 필요합니다. 사내 Windows 및 실제 네트워크 차단 환경 검증은 아직 수행하지 않았습니다.

## 사용

- 공정: S1 탭 용접·테이프 후 / S2 패키징 후 / S3 완제품. Stack 직후 제외.
- 마우스 드래그 회전, 휠 확대, 오른쪽 드래그 이동. 앞·뒤·측면과 선택 부품 집중.
- 몸체 및 양끝 리드 공통 치수, 테이프 크기 편집. 부품별 숨기기.
- 이름·그룹·측정 종류를 지정하고 두 기준점 선택 시작. 면 중심 스냅 또는 표면 자유 점을 두 번 클릭.
- 몸체 폭 예시 추가로 알려진 폭 확인. 치수별 슬라이더로 치수선 배치.
- 개별/전체 표시, 그룹 토글, 이 치수만 표시, 이름·그룹·부품 검색. 공정별 측정 목록.
- JSON 저장·불러오기: 형상, 측정, 표시 여부, 장면 설명, 카메라 복원. 브라우저 새로고침 전 반드시 저장.

## 검증 및 한계

[기준 문서](docs/cell-spec-management.md) · [검증과 인계](docs/handoff.md)

계산·참조 갱신·무효 참조·입력 검증·1,000항목 저장 복원 등 7개 자동 테스트 통과 및 production 빌드 성공. 브라우저 SVG 호환 경로에서 세 공정 전환, 폭 변경 계산, 측정 추가, 전체 표시 제어를 확인했습니다.

현재는 단순화된 파라메트릭 표시 모델입니다. CAD·STEP, 정확한 접힘·주름, 두께 방향 라운드, 실링 편집, 개별 리드 독립 편집, 공차/검사값 입력, 위치별 두께 지도, 완전한 충돌 검사는 미구현입니다. 표면 자유 점은 정규화 위치로 추종하며 형상 변경 시 제거된 모서리 위치는 무효 처리합니다. 1,000항목 동시 렌더링 성능은 검증하지 않았습니다.

사진·로고·실제 식별번호는 포함하지 않습니다. 극성은 예시에서 미확정입니다.
