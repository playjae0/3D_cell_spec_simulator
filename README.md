# 3D Cell Spec Simulator

파우치 셀 제조 스펙 관리 프로젝트입니다. 공개 가능한 가상 형상·데이터로 개발하고 실제 제조 스펙은 사내 운영본에서 관리합니다.

[제조 스펙 관리 기준 문서](docs/cell-spec-management.md)

## 현재 상태

2026-11-17: 사용자 제공 v0.3 기반 요구사항과 구현 명세를 정리했습니다. 현재는 문서 단계이며 실행 가능한 앱·의존성·테스트 코드는 없습니다. 과거 채팅 시연 소스는 포함되어 있지 않습니다.

## 첫 구현 목표

- S1 탭 용접·테이프 부착 후, S2 패키징 후, S3 완성 셀의 가상 형상
- 양끝 리드와 개별 부품 선택, 회전·확대·이동
- 형상 변수 편집, 직선 거리 및 축 투영 치수, 유효 참조 추종
- 버전이 있는 JSON 저장·복원

기술 스택, CAD 커널 및 STEP 지원은 미확정입니다. 실행 명령은 구현 후 검증 결과와 함께 추가합니다. 사진 원본과 실제 사내 데이터는 포함하지 않습니다.
